# Dashboard

Plotly Dash application (implemented in Workshop #4), served at `http://localhost:8050`.

Planned views (from the user stories in the Workshop #1 report):
- Map of the Landslide Risk Indicator (LOW / MEDIUM / HIGH) per 0.25° analysis cell, with 24-hour and 7-day rainfall and the latest LHASA value.
- Historical comparison: current 7-day rainfall vs. the distribution for the same cell and month, and past landslides (2007–2017) nearby.
- Data health: last update and watermark age per source, rejected records, missing LHASA days.

Attribution shown in the footer: NASA Global Landslide Catalog, NASA LHASA, weather data by Open-Meteo.com (CC BY 4.0).
