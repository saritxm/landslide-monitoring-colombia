# Interactive Dashboards — Workshop #4 (Plotly Dash)

Presentation layer of the **Landslide Monitoring and Risk — Colombia** platform (Team 7, Data Analysis Programming, Semester 2026-I).  
Both web applications are built with **Plotly Dash** and **Dash Bootstrap Components** and read **exclusively** from the Gold layer Parquet files (`datalake_gold/governance_*.parquet` and `datalake_gold/storytelling_*.parquet`) via `pd.read_parquet()`.

---

## Module Structure

| File | Port | Audience | Purpose |
| :--- | :---: | :--- | :--- |
| `dashboard/utils.py` | — | Shared | Loads the latest Gold Parquet file (`pd.read_parquet()`), defines the Okabe-Ito colorblind-safe palette, and renders standardized headers, footers, and chart source annotations. |
| `dashboard/governance_app.py` | `8050` | Technical (`US-06`) | Data governance and quality observatory auditing completeness, uniqueness, validity, accuracy, and pipeline timeliness. |
| `dashboard/storytelling_app.py` | `8051` | Functional (`US-01`–`US-04`) | Operational landslide risk dashboard designed for UNGRD emergency-management analysts. |

---

## 1. Governance Dashboard (`http://localhost:8050`)

- **Data Source:** Latest `datalake_gold/governance_*.parquet` (auto-refreshes every 60 seconds or on demand via the **Refresh Gold Data** button).
- **Components:**
  - **KPI Summary Cards:** Total Silver records, mean/max column null rate, duplicate rate before vs. after Gold deduplication, and schema compliance rate.
  - **Null Rate Bar Chart:** Horizontal bar chart of field null/empty rates ordered by severity.
  - **Volume Over Time Chart:** Daily ingested record volume across processing dates by source topic.
  - **Outlier & Quality Flag Rate Chart:** Percentage of records flagged by IQR/Z-score statistical rules and domain quality checks.
  - **Pipeline Compliance Chart:** Ingestion schedule compliance and schema/physical-bounds compliance against a 90% SLA threshold.
  - **Data Quality Summary Table:** Interactive, sortable, and filterable table comparing every governance KPI against defined operational thresholds (`PASS`, `WARN`, `ALERT`).

---

## 2. Storytelling Dashboard (`http://localhost:8051`)

- **Data Source:** Latest `datalake_gold/storytelling_*.parquet`.
- **Components:**
  - **Operational Narrative Summary Card (`US-01`):** Plain-language situational summary highlighting the highest-risk monitoring point and rainfall anomaly.
  - **Interactive Filters:** Filter views dynamically by **Department**, **Alert Level** (`LOW`, `MEDIUM`, `HIGH`), and **Focus Station**.
  - **Alert Level Distribution Donut Chart (`US-01`):** Breakdown of monitoring points using semantic color encoding (`LOW` = green, `MEDIUM` = amber, `HIGH` = red).
  - **Spatial Risk Map (`US-01`, `US-04`):** Interactive OpenStreetMap view of the 10 Andean monitoring stations sized by Landslide Risk Index (LRI) alongside historical NASA GLC landslides within 30 km.
  - **Hourly Rainfall Trend (`US-02`):** Observed vs. forecast hourly precipitation (`mm/h`) for the selected station.
  - **Daily Rainfall vs. Historical P90 (`US-03`):** Daily precipitation totals contrasted against the 10-year ERA5 90th percentile threshold for the current calendar month.
  - **Multi-Source Signal Comparison:** Side-by-side comparison of the Open-Meteo API 5-day rainfall anomaly ratio against the scraped NASA LHASA hazard index.
  - **Top Keywords by Severity (`US-04`):** Most frequent terms in NASA GLC narratives colored by mean fatalities per event.
  - **Historical Activity & Triggers (`US-04`):** Yearly landslide counts (2007–2017) and breakdown by reported trigger category.

## Execution

Ensure Gold Parquet files exist in `datalake_gold/` (generated by `gold_processing_dag` in Airflow or `python -m src.gold.transformations`), then run both applications from the repository root in separate terminals:

```bash
# Install dashboard dependencies (if not already installed)
pip install -r requirements.txt

# Terminal 1 — Governance Dashboard (http://localhost:8050)
python dashboard/governance_app.py

# Terminal 2 — Storytelling Dashboard (http://localhost:8051)
python dashboard/storytelling_app.py
```
